YAVIR Private Backup

A personal backup connection for its account owner. It uses restic and rclone to store encrypted, versioned copies of selected local files in the owner's existing Google Drive.

The connection requests access only to Google Drive files it creates or files explicitly opened with it. It does not request access to all existing Drive files. Backup contents are encrypted on the owner's computer before upload.

This is a private utility, not a public backup service. It does not invite other users, offer paid plans, or collect analytics on this page.
